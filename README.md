# Akala Labs

Marketing site for Akala Labs — the real-world layer for AI.

```bash
npm run dev
```

## Domain (you complete)

1. Buy **akalalabs.com** (Porkbun, Namecheap, or Cloudflare Registrar).
2. After Vercel is linked, add the domain in the Vercel project → Settings → Domains.
3. At your registrar, set DNS as Vercel shows (usually):
   - `A` `@` → `76.76.21.21`
   - `CNAME` `www` → `cname.vercel-dns.com`

Contact on the site is `founders@akalalabs.com`.
